# 视频脚本 · 《我给自己写了个待办+思维导图工具》

> **成片目标**：8～11 分钟（B站软件类甜区）
> **身份**：我是开发者本人，无第三方赞助
> **核心主张**：待办工具的真正瓶颈不是"记"，是"记完就忘"；这个工具把「拆解」和「执行」放同一屏

---

## 0. 拍前准备（15 分钟能搞定）

| 项 | 要求 |
|---|---|
| 录屏分辨率 | 1920×1080，浏览器缩放 100%，**关掉所有插件和通知** |
| 浏览器 | Chrome 无痕窗口（避免插件弹窗） |
| 素材 | 先把演示数据准备好：3 个清单、6 条任务、2 个子任务、3 张便利贴（1 张图片） |
| 录屏软件 | OBS / Screen Studio 均可，**不要录系统声音**（后期配音更清楚） |
| 收音 | 领夹麦；口播单独录，后期混音（现场录屏 + 口播分开，后期对轴更准） |
| 顺带拍 | 手机竖屏单独录 30 秒（结尾引导用） |

**演示数据建议**（观众能秒懂）：

- 清单：`工作` `生活` `评测拍摄`
- 任务：`写视频脚本`（高）`剪片头`（高）`买猫粮`（低）`回邮件`（中）
- 子任务：`找素材` `录屏` `剪辑`
- 便利贴：一张写"这期要讲的 3 个点"，一张贴截图

### 00:00–00:12 ｜ 钩子（结果前置）

**画面**：你正在用这个工具的画板（子任务 + 便利贴都在），鼠标随手拖一下便利贴让它变大。

**字幕**：`记待办` 和 `想事情` 两组词分别高亮
**剪辑**：前 3 秒不要 logo、不要片头，直接从动作切入

### 00:12–00:30 ｜ 亮身份 + 亮结论

**画面**：切到三栏界面全景，鼠标不动。

**口播**：
> 「这期没有恰饭，也没有赞助，因为这软件是我自己写的、自己部署的、自己每天在用的。
> 先说结论：**它适合'一件事需要拆开想'的人，不适合团队、不适合重度 GTD。**

**字幕**：`我是开发者 · 无赞助`

---

### 00:30–01:20 ｜ 痛点（为什么造它）

**画面**：录屏切到**别的工具的截图**（滴答清单/幕布各 1 张，快速切换，每个 1.5 秒）。

**口播**：
> 「先看两个我用过的。
> 滴答清单：记条目极快，但'一件事拆成三步'只能塞在描述里，写完就没人再看。
> 幕布：拆解很漂亮，但**拆完的结论不会自动变成一条待办**——
> 于是我拆完还得手动去另一个 App 抄一遍。」

**字幕**：`记完就忘` / `拆完还要抄一遍`
**剪辑**：每张别的工具的截图停留不超过 2 秒，快切

---

### 01:20–03:00 ｜ 核心功能演示（快节奏，每 30 秒一个点）

#### ① 建任务（00:1:20–01:45）

**画面**：中间栏输入框，打字「写视频脚本」，回车。

**口播**：
> 「先记一条。中间这栏，打字，**回车**。
> 我实测过，从按下回车到这行出现在列表里，**47 毫秒**。」

**字幕**：`47ms`
**剪辑**：回车后立刻切一个特写放大

#### ② 优先级分组（01:45–02:05）

**画面**：右键一条任务 → 优先级 → 高优先级。

**口播**：
> 「任务自动按高、中、低分成三组，不用自己建文件夹。
> 改优先级右键就行。」

#### ③ 截止日期（02:05–02:25）

**画面**：鼠标悬停任务行 → 右侧浮出日历图标 → 点开选"明天"。

**口播**：
> 「截止日期：鼠标划过去，右边会浮出一个小日历。
> 我知道你们想问——**它到点不会提醒你**，就一个日期标签。这是我后面要说的缺点之一。」

**字幕**：`不会提醒（缺点①）`

#### ④ 思维导图画板（02:25–03:00）⭐ 重点

**画面**：点开任务 → 右侧画板展开 → 拖动画布 → 滚轮缩放 → 指向右下角 MiniMap。

**口播**：
> 「然后是我觉得最值的部分：**点开任务，右边自动展开画板。**
> 父任务在中间，子任务用折线连出来。
> 画布可以拖、可以缩放，右下角这个是**全局缩略图**，节点多了也能看清自己在哪。
> 最关键的是——**中间栏和画板是同一份数据**，
> 这里加子任务，那边立刻就长出来；反过来也一样。**不用来回切页面。**」

**字幕**：`同一份数据 · 两个视图`
**剪辑**：这里放一个**同步发生的转场**——中栏加子任务 → 立刻切画板 → 节点已经在了（强调"实时"）

### 03:00–04:10 ｜ 便利贴（差异化功能）

**画面**：点 ＋ 新建便利贴 → 点它写字 → `Esc` 退出 → 拖右下角小方块缩放（**本体和 MiniMap 同步变大**）→ 选中后上方出现「删除」按钮。

**口播**：
> 「画布上可以贴**便利贴**，文字或者图片。
> 点一下直接打字，Enter 换行，Cmd+Enter 保存。
> 拖右下角这个方块可以缩放，而且**是实时的**——你看右下角那个缩略图，它跟着一起长。
> 这个地方我前后修了三轮，中间还踩了个'缩略图动、便签不动'的坑，
> 最后发现是**两个视图读的不是同一个数据源**，把它统一了才修好。」

**字幕**：`实时同步`
**弹幕埋点 ②**：「缩放能不能也别这么小方块？」

### 04:10–05:20 ｜ 亮点：后台 + 真实数据

**画面**：切到 `/admin` 后台（仪表盘 → 审计日志）。

> 但它后来救了我一次：有次数据出问题，我第一反应就是去审计日志翻'谁在什么时候改了什么'。」

### 05:20–08:00 ｜ 缺点段（这期最重要的部分）⭐

**画面**：保持主界面，边讲边切对应画面。

**口播**（每条给一个画面，避免口播太平）：

> 「下面这段是我自己用出来的**真实问题**，不是客套话。」

**① 没有搜索**（画面：在清单间来回点）
> 「第一个，也是最痛的一个：**没有全局搜索**。
> 任务一多，想找一条只能靠翻清单。」

**② 没有提醒**（画面：点一个带日期的任务）
> 「第二个：**到点不提醒**。就是个日期标签。
> 我现在的土办法是——有 deadline 的事单独放一个清单，每天早上开一次看一遍。笨，但管用。」

**③ 不能协作**（画面：停在用户管理页）
> 「第三个：**多人协作基本没有**。各用各的，没有共享清单、没有指派、没有评论。
> 想同步进度，只能截图发微信。」

**④ 多端会打架**（画面：两个浏览器窗口并排，一个删清单，另一个变回来）⭐
> 「第四个，这个我最不想说但必须说：**多端同时开会互相覆盖。**
> 我用一个窗口删掉一个清单，**另一个还开着的旧标签页**把旧数据又推回去了，那个清单就'复活'了。
> 说人话就是：客户端全量推送 + 服务端最后写入者赢，**没有版本冲突处理**。
> 所以现在的规矩是：**改完就刷新，只留一个标签页。**」

**⑤ 其他**（快速字幕条）
> 「剩下几个小的：**没有导出**，数据备份得我自己写脚本；
> **手机上画板基本没法编辑**，手指头拖不动小方块；
> 还有非管理员打开页面，控制台会有一条 403 报错。」

**字幕**：`没有搜索` `没有提醒` `没有协作` `多端会覆盖` `没有导出`

**弹幕埋点 ③**：「补上搜索我就付费」

## 4. 剪辑要点

| 项 | 做法 |
|---|---|
| 节奏 | 每 20～30 秒必须换一次画面或角度（换 tab / 换窗口 / 特写） |
| 加速 | 打字、建任务这种等待，**剪掉**（别让观众看光标闪） |
| 字幕 | 只压关键词（`47ms` `实时同步` `没有搜索`），不要整句照念 |
| 高亮框 | 讲到关键 UI（删除按钮、拖手、小方块）时用**圆角高亮框**弹一下 |
| 录屏清晰度 | 浏览器缩放 125%～150%，保证字在手机上看得清 |
| 封面帧 | 从 00:30 的三栏全景截，做封面 A |
| 背景音 | 轻电子/BGM，音量压到人声 -18dB 以下 |

## 5. 发布前 checklist

- [ ] **利益关系披露**放在简介开头（"我是开发者，无赞助"）——这条不是可选项
- [ ] 标题里**不出现**"最强""吊打""全网第一"（《网络测评活动规范》反对绝对化表述）
- [ ] 缺点段**完整保留**，不要剪成只剩优点（"全是优点的测评"在 B站会被当成广告直接劝退）
- [ ] 封面用**视频里的真实截图**，不要用美化图（封面欺诈会被点踩举报）
- [ ] 对比别的工具时，**用同一套标准**（不要用 A 的优点比 B 的缺点）
- [ ] 简介放地址 + 游客体验说明，别写微信号（小红书站外引流会限流）
- [ ] 小红书版另剪一版：**竖屏、3～6 张图、前 3 行给钩子**（文案见评测稿末尾）
