# Todo App 新手使用指南（小白版，3 分钟上手）

> 地址：**juststartit.cn**
> 打开后点 **「游客体验」** 就能直接用，**不用注册**。
> 想用自己的数据 → 手机号 + 密码注册。

---

## 0. 先做这 3 件事（3 分钟）

1. 打开网站 → 点「游客体验」→ 进首页
2. 左上角点 **「+」** 新建一个清单（会自动起个水果名，比如"榴莲"，可以右键重命名）
3. 中间栏顶部输入框打几个字 → **按回车** → 第一条待办就建好了

就这三步，你已经会用这个 App 80% 的功能了。

## 1. 界面导览：三栏

界面分成三栏，从左到右：

| 区域 | 位置 | 干什么 |
|---|---|---|
| **清单列表** | 最左 | 你有哪些"项目/分类"，比如「工作」「生活」 |
| **任务列表** | 中间 | 某个清单下的所有待办，按优先级自动分三组 |
| **任务画板** | 最右 | 当前任务的思维导图 + 便利贴 |

**三栏是联动的**：在中间点一条任务 → 右边立刻显示它的子任务和便利贴。

底部还有两个固定区段：**「已完成」**（跨清单汇总所有已完成的任务）和**「垃圾桶」**（所有删掉的任务）。

## 2. 清单（最左栏）

| 想做什么 | 怎么做 |
|---|---|
| 新建清单 | 点「清单列表」右上角的 **＋** |
| 重命名清单 | **右键**清单 → 重命名 |
| 置顶清单 | **右键** → 置顶（置顶的排在最前面） |
| 删除清单 | **右键** → 删除 |
| 调整顺序 | 按住清单**左边的小圆点**上下拖 |

> ⚠️ 删清单时，它下面的任务会**一起进垃圾桶**（不会真删，可以恢复）。

---

## 3. 任务（中间栏）

### 建任务
顶部输入框「添加新任务，按回车键可创建」→ 打字 → **回车**。实测 47 毫秒就出现在列表里。

### 优先级
任务名左边有一根**彩色小竖条**：
- 🟠 橙 = 高优先级
- 🔵 蓝 = 中优先级
- ⚪ 灰 = 低优先级

**改优先级**：右键任务 → 优先级 → 选一个。
**任务按优先级自动分成三组**显示，不需要自己建文件夹。

### 截止日期
- **鼠标停在任务行上** → 右侧浮出一个小日历图标 → 点它选日期
- 或者：右键 → 设置截止日期 → 今天 / 明天 / 下周一 / 清除

设了日期会在任务名后面显示一个徽章，**逾期会变红**。

### 完成任务
点任务**最左边的圆框**。完成的会打勾、划横线、自动移到「已完成」区段。

### 改任务名
**单击任务名**就能改（不用双击），改完按回车或点别处保存。

### 删任务
- 鼠标停在任务行上 → 点右侧出现的**垃圾桶**图标（直接进垃圾桶）
- 或右键 → 删除

> 💡 小技巧：任务名里写网址会自动变成可点击的链接。

---

## 4. 回收站（最左栏最下面）

删掉的任务都在这，不会真丢。

| 操作 | 怎么做 |
|---|---|
| 恢复 | 选中任务 → 点"恢复" |
| 永久删除 | 选中任务 → 点"永久删除" |
| 清空 | 回收站右上角有清空按钮 |

## 5. 思维导图画板（最右栏）

点中间栏的任意一条任务 → 右边展开它的画板。

| 想做什么 | 怎么做 |
|---|---|
| 移动画布 | 按住空白处拖 |
| 缩放 | 滚轮 / 左下角 **＋ －** 按钮 / 双击空白处适应视图 |
| 全屏 | 右上角 **⛶** 按钮 |
| 看全局 | 右下角的**缩略图**（MiniMap），点它可以跳到对应位置 |
| 加便利贴 | 右上角 **＋** 按钮 |

画板上的节点：

- **父任务**在中间，**子任务**连在右边（直角折线）
- **便利贴**是黄色小卡片，可以贴文字或图片

## 6. 便利贴（重点）

### 写内容
**单击便利贴** → 里面出现输入框 → 直接打字。

| 按键 | 作用 |
|---|---|
| `Enter` | 换行 |
| `Cmd/Ctrl + Enter` | 保存并退出 |
| `Esc` | 退出编辑（内容保留） |

### 移动 / 缩放
- **拖动**便利贴本体 = 移动位置
- **拖动右下角的小方块** = 缩放大小（**实时生效**，便签和右下角缩略图同步变化）

### 删除
1. 选中便利贴后，它的**上方会出现「删除」按钮** → 点它
2. 或者：按 `Esc` 退出编辑 → 按 `Backspace` / `Delete`

> ⚠️ **编辑状态下按 Backspace 只会删文字，不会删便利贴**——这是很多人第一次用会困惑的地方。

### 贴图片
- 直接 **Ctrl/Cmd + V** 粘贴截图 → 自动变成图片便利贴
- 或在画板里粘贴图片

### 改名
**双击**便利贴 → 弹窗改名。

---

## 7. 子任务

在中间栏顶部有「＋ 子任务」输入框，输完回车就加上了。

**子任务和画板是双向的**：
- 中间栏加的子任务 → 画板上同步长出来
- 画板上的子任务节点 → 中间栏同步出现

## 8. 手机上怎么用

手机上界面会变成**底部三个 tab**：

```
┌─────────────────────┐
│                     │
│    当前 tab 内容      │
│                     │
├─────────────────────┤
│  清单    任务    画板  │
└─────────────────────┘
```

- 点底部 tab 切换三栏
- 右上角 **☀** 切换深色模式
- 右上角 **⋮** 打开菜单（改密码 / 退出登录等）

**手机上适合**：记任务、勾完成、看清单。
**不适合**：在画板上拖拽节点（手指太粗，拖不动那些小方块）。

## 10. 快捷键速查

| 场景 | 按键 | 作用 |
|---|---|---|
| 任意列表 | 输入框打字 + `Enter` | 新建任务/子任务/清单 |

## 11. 常见问题

**Q：点进去发现别人的数据？**
A：游客体验用的是**公共账号**，数据是大家的，会互相干扰。**重要东西请注册自己的账号**。

**Q：我删掉的东西刷新后又回来了？**
A：如果你的浏览器**同时开着两个标签页**，旧标签页会把旧数据推回去覆盖掉。
→ **改完就刷新，只留一个标签页**。这是目前已知的问题。

**Q：清单删了，里面的任务去哪了？**
A：进「垃圾桶」，它们都在，可以恢复。

**Q：能多人一起用吗？**
A：目前**不能**。每个人一套清单各用各的，没有共享和指派。

**Q：到点了会提醒我吗？**
A：**不会**。只有日期徽章，靠你自己看。

**Q：能搜任务吗？**
A：目前**没有全局搜索**，只能按清单翻。

**Q：我的数据存在哪？**
A：在运行这个服务的那台服务器上（国内）。注册后只有你自己能看到。

## 12. 一句话总结

**「左边分项目，中间记待办，右边拆思路。」**
记一条只要 47 毫秒，拆解和执行在同一屏。
